# Ảnh giao diện HTTD 3.0 — giai đoạn 1 và 1b

Chụp từ mã nguồn hiện tại chạy với máy chủ thử (dữ liệu mẫu), ở hai cỡ màn hình: điện thoại 390 px và máy tính 1366 px.

| Ảnh | Nội dung |
|---|---|
| 01-dien-thoai-dang-nhap | Màn đăng nhập: nút Google và tên + mật khẩu |
| 02-dien-thoai-hom-nay | Màn Hôm nay, thanh điều hướng dưới |
| 03-may-tinh-danh-muc-don-vi | Danh mục chung, bảng 36 đơn vị, cột mã cố định |
| 04-may-tinh-sua-danh-muc-nhat-ky | Tấm trượt sửa một dòng, tab Nhật ký có căn cứ |
| 05-may-tinh-quan-tri | Người dùng, Sức khỏe hệ thống |
| 06-may-tinh-nhat-ky | Nhật ký hệ thống |
| 07-dien-thoai-danh-muc | Danh mục trên điện thoại, dải chọn bảng cuộn ngang |
| 08-dien-thoai-them-bao-loi | Thêm trùng mã: báo lỗi, dữ liệu đã gõ giữ nguyên |
| 09-may-tinh-ban-toi | Giao diện tối tự theo cài đặt máy |
| 10-may-tinh-bo-chi-tieu | (1b) Bộ chỉ tiêu: danh sách bộ theo loại hệ thống, cây chỉ tiêu, tấm trượt chi tiết TT13-BNV:0101 với năm mục nội dung |
| 11-dien-thoai-bo-chi-tieu | (1b) Bộ chỉ tiêu trên điện thoại: dải chọn bộ, lọc "Chỉ cấp xã", tìm, cây LUAT-TK |
| 12-dien-thoai-chi-tiet-chi-tieu | (1b) Chi tiết chỉ tiêu trên điện thoại, nội dung giữ xuống dòng như văn bản |
| 13-may-tinh-nhap-bo-chi-tieu | (1b) Nhập bộ chỉ tiêu: xem trước, lỗi theo số dòng Excel, nút Ghi bị khóa khi còn lỗi |

Ảnh 10–13 chỉ dùng dữ liệu văn bản công khai (TT 13/2025/TT-BNV, Luật Thống kê); không chụp Phụ lục 699 vì là dữ liệu nội bộ.
